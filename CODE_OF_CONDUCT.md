# Code of conduct

The xqmob project aims to maintain a professional, technically rigorous and
welcoming collaboration environment.

Participants are expected to:

- discuss ideas and code rather than attacking people;
- give specific, evidence-based technical feedback;
- respect differences in experience, background and communication style;
- avoid harassment, discrimination, threats and deliberately disruptive conduct;
- handle sensitive security or data issues through appropriate private channels;
- assume good intent while remaining willing to correct mistakes.

Maintainers may edit, hide or remove contributions that materially undermine
these expectations, and may restrict participation when necessary to protect
the project or its contributors.

If conduct needs maintainer attention, use a private maintainer contact route
rather than escalating a personal dispute in public project threads.
